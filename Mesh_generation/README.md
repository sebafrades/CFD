# Mesh Generation

This folder contains implementations of **CFD mesh-generation methods developed from scratch**, mainly using C++.

The main focus is on structured grids generated from elliptic partial differential equations.

## Projects

### `Poisson_2D_Channel_parabolic_bump`

A two-dimensional channel with a parabolic bump is used to study elliptic mesh generation.

The mesh is generated by solving a **Poisson equation using finite differences**. The resulting grid is then used to construct a corresponding **finite-volume mesh**, including the geometric and topological information required by a finite-volume solver.

The finite-volume mesh implementation is being developed from scratch, using the OpenFOAM programming guide as a reference for understanding mesh representation and data structures.

The corresponding CFD solver is currently under development.

### Other mesh-generation methods

This folder also contains implementations based on the **Laplace equation** for elliptic mesh generation.

## Purpose

The goal is to understand the numerical and geometrical foundations of CFD mesh generation and to develop the components required by a CFD solver without relying on an existing CFD framework.
