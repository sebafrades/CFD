# CFD

This repository contains a collection of **Computational Fluid Dynamics (CFD) implementations developed from scratch**, primarily in C++ and Python.

The main goal is to understand CFD from the numerical and physical foundations up: discretization of governing equations, grid generation, finite-difference and finite-volume methods, boundary conditions, numerical solvers, and post-processing.

Rather than relying exclusively on existing CFD software, the projects in this repository are implemented progressively from the underlying numerical methods.

## Projects

### Poisson equation and finite-volume CFD

The main project currently under development is:

**`Poisson_2D_Channel_parabolic_bump`**

This project develops a CFD workflow for a two-dimensional channel containing a parabolic bump.

The mesh is generated by solving a **Poisson equation using finite differences**, providing an elliptic grid-generation approach for the physical domain.

The resulting grid is then converted into a **finite-volume mesh**, following the data structures and mesh concepts used in OpenFOAM. The finite-volume mesh implementation was developed by studying the OpenFOAM programming guide and its underlying mesh representation.

The current work focuses on implementing the **corresponding finite-volume flow solver from scratch**.

The project therefore follows the complete numerical workflow:

1. Generate a structured computational grid using an elliptic Poisson equation.
2. Convert the grid into a finite-volume mesh.
3. Construct the geometric and topological information required by the finite-volume method.
4. Implement the governing equations and their discretization.
5. Develop the numerical solver.
6. Post-process and analyze the results with Python.

The purpose is to understand the numerical structure of a CFD code at a deeper level, rather than treating a CFD package as a black box.

### MRCVC

`MRCVC` is a mesh-generation project for the combustion chamber of a **rotary combustion engine**.

The geometry is based on a rotary combustion engine developed by a former professor at my university.

### Classical unsteady problems

The repository also contains implementations of classical fluid-dynamics problems used to study numerical methods and verify the solvers:

* Second Stokes problem
* Transient Poiseuille flow
* Transient Burgers equation

These problems provide relatively simple analytical or well-established reference solutions for testing numerical implementations.

## Numerical methods

The projects in this repository currently involve:

* Finite differences
* Elliptic grid generation
* Laplace and Poisson equations
* Finite-volume methods
* Structured grids
* Numerical discretization of PDEs
* Boundary-condition implementation
* Numerical solution of transient problems
* CFD mesh and geometry representation

The code is being developed progressively in **C++**, with **Python** used for visualization and post-processing.

## Planned work

A separate **`OpenFOAM`** section is planned for implementations and studies carried out using OpenFOAM.

The long-term goal of the repository is to develop projects ranging from fundamental numerical implementations to complete CFD workflows, while maintaining a focus on understanding the methods behind the software.
